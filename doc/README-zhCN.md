# ZotWanglele 简体中文说明

ZotWanglele 是面向 Zotero 10 的 AI 阅读与 PDF 翻译插件。当前版本为 `0.1.7`。
完整使用说明、当前功能、开发命令与限制已经整合到仓库根目录的
[README](../README.md)。

## 当前功能摘要

- 多 AI 配置档与 OpenAI 兼容调用；供应商支持多个 Key，各 Key 获取模型后合并展示，翻译设置显示“供应商/模型名称”。
- 仪表盘第二个页签提供 AI 配置，与插件设置页面共享供应商、Key 和模型管理。
- PDF 划词翻译支持 AI、Google（实验性）、DeepL 与百度，选区浮层和阅读侧栏同步展示，支持流式输出、取消、复制与会话缓存。
- 基于 Zotero 全文索引的论文精读与快速摘要。
- `pdf2zh`、`pdf2zh_next` 子进程翻译。
- zotero-pdf2zh 服务端翻译。
- 默认使用 PDFMathTranslate 的 `google` 翻译后端，独立于 AI 配置档。
- 仪表盘提供任务记录、文献翻译设置和划词翻译设置；PDF 翻译按文献分开记录，批量信息更新和 AI 工作流按操作聚合，并提供卡片详情。
- Zotero 条目面板中的 AI 笔记预览，支持论文精读和快速摘要笔记的查看与生成。
- 仪表盘中的统一提示词管理：按功能浏览，管理该功能下的默认模板与自定义模板。
- Crossref 文献信息更新：按 DOI 查询、字段对比、逐字段确认和多条目串行处理。
