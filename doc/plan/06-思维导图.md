# 阶段 7：思维导图

## 阶段状态

本阶段处于规划状态。`src/modules/mindmap/` 当前仅含 `.gitkeep`，仓库中也没有
导图渲染依赖、导出实现或侧栏容器。

## 数据生成

规划方案以论文索引文本或已有 AI 笔记作为输入，要求模型返回树形 JSON。建议
的数据节点包含固定 ID、标题、说明和子节点数组。解析层需要进行 JSON 结构
校验，并处理缺失字段、过深层级与超长文本。

默认主题可覆盖研究背景、研究问题、方法、实验、结果、结论与局限。节点结构
应允许提示词自定义，避免固定为单一论文模板。

## 渲染与交互

候选方案包括 markmap 或 simple-mind-map。选型需要考虑 Zotero 9 内嵌环境、
`.xpi` 体积、离线资源、缩放、拖动、折叠和主题适配。

当前仓库尚无 `sidebar.xhtml`。导图可放入未来侧栏，也可使用独立窗口；该决策
需要结合阅读对话与笔记预览的整体布局。

## 导出规划

- PNG：从 SVG 或 Canvas 生成位图。
- OPML：将树形数据序列化为通用大纲格式。
- JSON：保留原始结构，便于再次编辑。

导出位置应由文件选择器确定，并保留失败提示。验收条件应覆盖大节点数量、中文
文本、深层级和导出文件重开验证。
