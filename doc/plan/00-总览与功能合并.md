# ZotWanglele 开发总览

## 项目定位

ZotWanglele 是面向 Zotero 10 的 AI 阅读与 PDF 翻译插件。项目采用
TypeScript、zotero-plugin-scaffold 和 zotero-plugin-toolkit，构建产物为单个
`.xpi` 文件。

项目参考 zotero-AI-Butler、AI4Paper 与 zotero-pdf2zh 的功能设计。仓库当前
聚焦 AI 配置、索引文本精读、PDF 翻译和任务展示，其他能力按阶段保留规划。

## 当前流程

### 划词翻译

PDF 原生选区浮层提供翻译操作，主窗口阅读侧栏同步显示当前阅读器的原文、译文、
服务和状态，独立窗口使用浮层。AI、Google（实验性）、DeepL 与百度已完成实现，
支持手动或延迟自动翻译、请求取消、复制以及最多 50 条的阅读器会话缓存。
设置单独保存在 `selectionTranslate.*`，AI 沿用配置档与提示词管理。
实现和验证范围见 [划词翻译](09-划词翻译.md)。

### AI 精读

用户在条目菜单中选择“论文精读”或“快速摘要”。插件读取第一个 PDF 附件的
Zotero 全文索引，截取最多 60000 个字符，调用当前 AI 配置档，并把结果保存为
原条目的子笔记。多选条目按顺序处理。生成的精读和摘要可在 Zotero 条目面板的
“AI 笔记预览”区块查看；区块也支持生成、刷新、打开原笔记、字号调整和高度设置。

### PDF 翻译

用户在高级设置中选择 `uv-auto`、`uv-manual`、`bundle` 或 `server`。条目菜单
会为每篇文献创建内存任务，执行 `pdf2zh` 或 `pdf2zh_next`，随后把选定的单语、
双语 PDF 导入原条目。多任务会异步运行，当前尚无并发上限。

翻译流程读取独立的 `translate.*` 设置。默认 `service` 为 `google`，表示
PDFMathTranslate 的 Google 机器翻译后端；AI 配置档仅参与论文精读。

### 文献综述与标题翻译

文献综述读取 2 至 30 个常规条目的题录与摘要。缺少摘要时，流程会读取有限的 PDF
索引文本。AI 结果保存为当前文献库中的独立笔记，并可加入当前分类。

标题翻译逐项调用当前 AI 配置档，将结果保存到 Extra 字段。插件通过
`Zotero.ItemTreeManager` 注册“标题译文”列，译文可在条目列表中显示和排序。

### Crossref 文献元数据更新

条目菜单中的“更新文献信息”读取常规条目的 DOI，串行查询 Crossref REST API。查询结果在模态窗口中与本地标题、作者、摘要、DOI 和日期逐项对照；用户选择字段后才写入条目。多选条目逐条处理，查询错误、无变化和取消操作分别显示在进度汇总中。

请求使用 `mailto=2971130350@qq.com`，更新时间和联系邮箱写入 Extra 的独立行，并保留条目原有内容。

### 统一任务记录

仪表盘通过进程内任务存储汇集用户发起的操作。PDF 翻译按文献各自创建记录，以便查看附件、进度和错误；文献信息更新、标题翻译、AI 笔记与文献综述按一次操作聚合为一条记录。任务卡片展示操作类型、处理对象、状态、进度和摘要，展开后显示条目级结果、日志、错误与输出文件。

### 数据存储

- AI 配置档与翻译设置保存在 Zotero prefs。
- 自定义提示词保存在 Zotero prefs。
- 标题译文保存在条目 Extra 字段。
- Crossref 更新成功后，在 Extra 中保存 `ZotWanglele-Crossref-Updated` 和
  `ZotWanglele-Crossref-Mailto` 行。
- API Key 位于配置档 JSON 中，当前没有独立密钥存储层。
- 统一任务记录位于进程内存，Zotero 重启后清空。
- 翻译中间文件位于系统临时目录，结果会另行导入 Zotero。
