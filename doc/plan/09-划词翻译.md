# 划词翻译

## 功能状态

0.1.8 支持 PDF 词语、句子与段落翻译、持久历史、多方案对比和文本长度规则。
默认手动触发，自动翻译为可选设置。
主窗口 PDF 标签页提供原生选区浮层和独立阅读侧栏区块，两个区域共享当前阅读器的
选区、服务、目标语言、译文与状态；独立 PDF 窗口提供浮层。原生批注操作继续保留。

结果用于查看与复制。关闭浮层后，右侧工具栏继续展示当前结果；关闭阅读器会清理
当前会话，已保存的历史跨阅读器和 Zotero 重启保留。真实账号与网络环境由用户启动
Zotero 验证。

## 操作方式

- 在仪表盘的“划词翻译设置”中添加文本长度方案，填写范围，添加翻译服务；选择 AI 时选择已有模型。源语言、目标语言和自动翻译位于“通用选项”。
- 在 PDF 中选择文字，点击“翻译”。AI 译文逐步显示，运行期间可点击“停止生成”。
- 完成后可逐项复制译文，也可复制全部方案或原文与译文。选中已有历史的文字时自动显示匹配结果；“翻译”和“重试未完成的翻译”均复用已完成的历史。
- 浮层与侧栏均可切换目标语言，翻译服务由匹配的长度方案决定。
- 自动翻译开启后，选区停留 600 毫秒触发。选区消失时，尚未开始的调用作废。
- 仪表盘的提示词管理提供“划词翻译”功能，支持内置模板修改和自定义模板。

## 翻译历史

设置页的“翻译历史”位于“翻译模型”之前，提供保存条数和最大缓存（MB）。
容量默认 50 MB，按 UTF-8 历史文件大小计算，与条数限制同时生效。超限时清理
较早记录；单条译文超过容量时跳过保存，已有记录保留。容量设为 0 时清空历史。

“翻译模型”上下均提供添加长度方案和保存方案按钮，每个方案显示一次“翻译服务”
标题。服务支持上移、下移，顺序在保存后用于展示译文。删除 AI 模型后，原位置显示
“未找到该模型”，可重新选择模型。

主窗口右侧工具栏的“划词翻译”区域包含历史列表，可搜索原文、译文与模型名称，
打开旧记录、删除单条记录或确认清空全部记录。每段原文及其语言组合计为一条，
该原文的多方案结果保存在同一条记录中；列表按最近完成时间排列。

工具栏和设置页均可修改记录数量上限，默认 100 条，支持 0–1000 条。降低上限会
移除超出的较早记录，0 表示关闭并清空历史。历史保存在当前 Zotero profile 的
`zotwanglele-selection-history.json` 中，以完整文件替换方式保存；界面提示读取或
保存错误，当前已完成的译文仍可查看和复制。

历史匹配使用整理后的原文、源语言、目标语言和实际翻译配置。AI 的服务地址、模型、
协议、生成参数和提示词变化会使对应译文重新生成；传统翻译服务按各自凭据和账户类型
判断。同一原文更改对比组合时，可复用组合中已有的译文；失败和被取消的半成品不写入历史。
历史仅保存译文、显示名称和配置摘要，凭据继续保存在原有偏好设置中。

## 多方案对比与长度规则

“文本长度方案”通过“添加翻译”逐项选择 Google、AI、DeepL 或百度。选择 AI 后显示模型下拉框，名称统一为“供应商/模型名称”。每个方案可添加多个服务与模型，各项译文独立显示进度、结果和错误。

方案可添加、排序和删除，修改后点击“保存方案”。翻译采用首个匹配范围；未匹配时显示补充范围的提示。旧翻译设置转换为可编辑的全长度方案，已有范围保留。保存空方案列表后，翻译会提示添加方案。

| 示例   | 计数方式 | 下限（包含） | 上限（排除） | 翻译方式              |
| ------ | -------- | ------------ | ------------ | --------------------- |
| 短文本 | 词数     | 0            | 10           | Google                |
| 长文本 | 词数     | 10           | 留空         | Google 与指定 AI 模型 |

词数按字母或数字组成的词计算，缩写中的撇号和词内连字符保留为一个词，汉字逐字
计数。字数按 Unicode 码点计算，包含标点、忽略空白。每条规则使用独立计数方式，
下限为非负整数，上限须大于下限；上限留空表示无限。每个范围至少选择一种翻译方式。

## 服务配置

| 服务   | 配置                     | 调用方式                                                   |
| ------ | ------------------------ | ---------------------------------------------------------- |
| AI     | 选择已有 AI 模型         | 共用 AiClient，支持 Chat Completions、Responses 与流式输出 |
| Google | 无需密钥，界面标记实验性 | `translate.googleapis.com/translate_a/single` 网页通道     |
| DeepL  | API Key、Free／Pro 类型  | HTTPS POST `/v2/translate`，请求头使用 `DeepL-Auth-Key`    |
| 百度   | AppID、密钥              | HTTPS POST 通用翻译服务，MD5 签名                          |

目标语言包括简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语和俄语。
源语言额外支持自动识别。Google 与百度按服务规则转换语言代码；DeepL 的中文源语言
使用 `ZH`，目标语言区分 `ZH-HANS` 和 `ZH-HANT`。

设置键位于 `extensions.zotero.zotwanglele.selectionTranslate.*`，与整篇 PDF 翻译分别保存。
服务密钥保存在本地 Zotero 偏好设置中，沿用项目现有配置方式。

依据：[DeepL 认证文档](https://developers.deepl.com/docs/getting-started/auth)、
[百度通用翻译文档](https://api.fanyi.baidu.com/doc/23)、
[Google 社区实现](https://github.com/ECHOUniverse/zotero-translator-next/blob/main/src/services/google.ts)。
腾讯传统翻译未纳入本版，新版服务作为后续候选；背景见
[腾讯云公告](https://cloud.tencent.cn/announce/detail/2448)。

## 实现结构

| 文件                                        | 用途                                                   |
| ------------------------------------------- | ------------------------------------------------------ |
| `src/modules/selection-translate/reader.ts` | 原生选区事件、侧栏注册、阅读器与标签页映射、卸载清理   |
| `session.ts`                                | 选区状态、多方案执行、历史复用、请求取消与过期响应检查 |
| `history.ts`                                | 持久历史、数量上限、搜索数据与文件保存                 |
| `services.ts`                               | 服务适配、语言代码、请求签名、响应解析与业务错误       |
| `text.ts`                                   | 空白整理、词数与字数计数、范围选择、字符上限与分段     |
| `view.ts`、`styles.ts`                      | 浮层、侧栏、纯文本展示、复制与纸感样式                 |
| `config.ts`、`preferences.ts`、`locale.ts`  | 设置读写、设置页面与本地化                             |
| `src/utils/request.ts`                      | 可取消 HTTP 请求、超时映射与可取消延迟                 |
| `src/modules/ai/ai-client.ts`               | AI 调用，扩展可选 `signal` 与 `timeoutMs`              |

阅读器实例是会话边界，侧栏通过所属 `item-details` 的标签页标识寻找阅读器。
相同父文献下的多个 PDF 分别保存选区和结果。新选区、设置变更及阅读器关闭会取消
相关调用，旧请求的增量与最终响应通过版本标记失效。

文本按 Unicode 码点计数，整理多余空白并移除软连字符，保留段落、公式和正常连字符。
单次上限 5000 字符；Google 分段上限 500 字符，百度上限 1500 字符，按句子或空白边界
串行处理。百度调用之间预留 1100 毫秒；AI 与 DeepL 处理完整选区。传统服务每次请求
超时为 30 秒，AI 为 60 秒。

阅读器分别管理当前选区和结果，共享持久翻译历史。数量上限、自动翻译开关和其他
服务的配置变化保留已完成译文的匹配关系。请求、定时器、界面订阅和偏好观察器随
相应生命周期清理。

内置提示词使用 `{{text}}`、`{{sourceLang}}`、`{{targetLang}}`，要求仅输出译文并保留
专有名词、数字、公式及段落。发送内容限定为选区文本。原文和译文使用纯文本显示。
