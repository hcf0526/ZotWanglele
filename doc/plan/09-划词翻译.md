# 划词翻译

## 功能状态

首版已实现 PDF 词语、句子与段落翻译。默认手动触发，自动翻译为可选设置。
主窗口 PDF 标签页提供原生选区浮层和独立阅读侧栏区块，两个区域共享当前阅读器的
选区、服务、目标语言、译文与状态；独立 PDF 窗口提供浮层。原生批注操作继续保留。

结果用于查看与复制，保留在阅读会话中。关闭浮层后，侧栏继续展示当前结果；
关闭阅读器或卸载插件后清空会话。当前版本包含基础服务与界面，真实账号与网络环境
仍需用户启动 Zotero 验证。

## 操作方式

- 在仪表盘的“划词翻译设置”中选择默认服务、源语言和目标语言。默认服务为 AI，源语言自动识别，目标语言简体中文。插件设置页面保留 AI 配置管理。
- 在 PDF 中选择文字，点击“翻译”。AI 译文逐步显示，运行期间可点击“停止生成”。
- 完成后可复制译文或原文与译文；“重新翻译”会发起新调用，忽略已有缓存。
- 浮层与侧栏均可切换服务或目标语言，点击“翻译”生成新结果。失败时按提示修改设置或切换服务。
- 自动翻译开启后，选区停留 600 毫秒触发。选区消失时，尚未开始的调用作废。
- 仪表盘的提示词管理提供“划词翻译”功能，支持内置模板修改和自定义模板。

## 服务配置

| 服务   | 配置                     | 调用方式                                                   |
| ------ | ------------------------ | ---------------------------------------------------------- |
| AI     | 当前配置或指定已有模型   | 共用 AiClient，支持 Chat Completions、Responses 与流式输出 |
| Google | 无需密钥，界面标记实验性 | `translate.googleapis.com/translate_a/single` 网页通道     |
| DeepL  | API Key、Free／Pro 类型  | HTTPS POST `/v2/translate`，请求头使用 `DeepL-Auth-Key`    |
| 百度   | AppID、密钥              | HTTPS POST 通用翻译服务，MD5 签名                          |

目标语言包括简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语和俄语。
源语言额外支持自动识别。Google 与百度按服务规则转换语言代码；DeepL 的中文源语言
使用 `ZH`，目标语言区分 `ZH-HANS` 和 `ZH-HANT`。

设置键位于 `extensions.zotero.zotwanglele.selectionTranslate.*`，与整篇 PDF 翻译分别保存。
服务密钥保存在本地 Zotero 偏好设置中，沿用项目现有配置方式。

依据：[DeepL 认证文档](https://developers.deepl.com/docs/getting-started/auth)、
[百度通用翻译文档](https://api.fanyi.baidu.com/doc/23)、
[Google 社区实现](https://github.com/ECHOUniverse/zotero-translator-next/blob/main/src/services/google.ts)。
腾讯传统翻译未纳入本版，新版服务作为后续候选；背景见
[腾讯云公告](https://cloud.tencent.cn/announce/detail/2448)。

## 实现结构

| 文件                                        | 用途                                                 |
| ------------------------------------------- | ---------------------------------------------------- |
| `src/modules/selection-translate/reader.ts` | 原生选区事件、侧栏注册、阅读器与标签页映射、卸载清理 |
| `session.ts`                                | 选区状态、请求取消、过期响应检查、订阅与会话缓存     |
| `services.ts`                               | 服务适配、语言代码、请求签名、响应解析与业务错误     |
| `text.ts`                                   | 空白整理、软连字符处理、字符上限与分段               |
| `view.ts`、`styles.ts`                      | 浮层、侧栏、纯文本展示、复制与纸感样式               |
| `config.ts`、`preferences.ts`、`locale.ts`  | 设置读写、设置页面与本地化                           |
| `src/utils/request.ts`                      | 可取消 HTTP 请求、超时映射与可取消延迟               |
| `src/modules/ai/ai-client.ts`               | AI 调用，扩展可选 `signal` 与 `timeoutMs`            |

阅读器实例是会话边界，侧栏通过所属 `item-details` 的标签页标识寻找阅读器。
相同父文献下的多个 PDF 分别保存选区和结果。新选区、设置变更及阅读器关闭会取消
相关调用，旧请求的增量与最终响应通过版本标记失效。

文本按 Unicode 码点计数，整理多余空白并移除软连字符，保留段落、公式和正常连字符。
单次上限 5000 字符；Google 分段上限 500 字符，百度上限 1500 字符，按句子或空白边界
串行处理。百度调用之间预留 1100 毫秒；AI 与 DeepL 处理完整选区。传统服务每次请求
超时为 30 秒，AI 为 60 秒。

每个阅读器保留最多 50 条 LRU 缓存。文本、语言、服务设置、AI 模型及提示词内容共同
决定缓存身份；配置凭据仅以摘要参与缓存身份计算。缓存、请求、定时器、界面订阅和
偏好观察器均随相应生命周期清理。

内置提示词使用 `{{text}}`、`{{sourceLang}}`、`{{targetLang}}`，要求仅输出译文并保留
专有名词、数字、公式及段落。发送内容限定为选区文本。原文和译文使用纯文本显示。
