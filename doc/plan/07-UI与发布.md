# 阶段 8-9：用户界面与发布

## 阶段状态

基础用户界面已经覆盖 AI 配置、条目菜单、工具栏入口、翻译任务、翻译设置和阅读侧栏。
概览、提示词管理和 AI 笔记预览已经可用；`0.1.6` 作为当前发布基线，设置页面、
仪表盘、配置编辑器、元数据窗口、操作确认框、插件进度提示与 AI 笔记预览已统一
纸感视觉主题。后续版本预计以安装、扩展生命周期和界面兼容性 bug 修复为主。

仪表盘采用单例窗口。重复打开会聚焦已有窗口并切换页签；窗口关闭时会移除任务
订阅和按钮事件。

设置页面样式通过 `src/modules/preferenceScript.ts` 的 `injectPrefsStylesheet`
在运行时注入 `paper-theme.css` 与 `preferences.css`：Zotero 解析偏好面板 XHTML 片段时会丢弃顶部
`xml-stylesheet` 声明，静态引用无法生效。AI 笔记预览的样式内嵌在
`note-preview.ts`，内容容器使用 `contain: inline-size` 让 Zotero 决定侧栏
宽度，避免长内容撑破面板；模板切换为自定义下拉，避免原生 `select` 弹层随
面板宽度调整闪烁。

`paper-theme.css` 保存纸面、文字、分隔线和功能色变量。仪表盘、配置编辑器、
元数据窗口与操作确认框加载该文件；插件创建的 Zotero 进度提示在显示后注入
纸感主题，保留 Zotero 原有的任务行为与关闭方式。

## 本地化

`addon/locale/zh-CN/` 与 `addon/locale/en-US/` 覆盖偏好设置、配置编辑器和仪表盘
的基础文本。高级翻译面板与任务卡片仍包含源码内中文，后续需要迁移至 Fluent。
法语文档属于项目说明，插件界面当前没有法语资源。

## 测试状态

`test/startup.test.ts` 检查插件全局对象、条目菜单、自定义列和仪表盘工具栏按钮。
`test/features.test.ts` 检查标题译文元数据、综述来源格式与提示词持久化操作。
`test/translation.test.ts` 使用真实 Zotero 条目与指定 PDF，覆盖右键翻译、任务页
中间进度、完成状态及两类结果附件。精读与配置编辑器的数据保存流程仍缺少完整自动化覆盖；
启动测试已检查配置编辑器和元数据结果窗口的主要按钮样式。

发布候选版本需要完成以下验证：

- `npm run build`
- `npm run lint:check`
- `npm test`
- Zotero 10 中的安装、启停、偏好设置、菜单、窗口与附件导入验证
- `uv` 三种本地来源与 zotero-pdf2zh 服务端模式验证

## 发布流程

当前发布版本为 `0.1.6`，已完成本地发布基线。项目脚本提供 `npm run release`，远程 GitHub
Release 需要后续推送 `v0.1.6` 标签后由 Actions 创建。构建产物位于 `.scaffold/build/`。
