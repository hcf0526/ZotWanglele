# 阶段 8-9：用户界面与发布

## 阶段状态

基础用户界面已经覆盖 AI 配置、条目菜单、工具栏入口、翻译任务、翻译设置和阅读侧栏。
概览、提示词管理和 AI 笔记预览已经可用；当前版本为 `0.1.8`，设置页面、
仪表盘、配置编辑器、元数据窗口、操作确认框与 AI 笔记预览采用纸感视觉主题。
进度提示沿用 Zotero 默认外观并保留衬线字体。仪表盘目前提供六个页签：概览、
AI 配置、任务记录、提示词管理、文献翻译设置和划词翻译设置。

仪表盘采用单例窗口。重复打开会聚焦已有窗口并切换页签；窗口关闭时会移除任务
订阅和按钮事件。

设置页面样式通过 `src/modules/preferenceScript.ts` 的 `injectPrefsStylesheet`
在运行时注入 `paper-theme.css`、`preferences.css` 与 `ai-config.css`：Zotero 解析偏好面板 XHTML 片段时会丢弃顶部
`xml-stylesheet` 声明，静态引用无法生效。AI 笔记预览的样式内嵌在
`note-preview.ts`，内容容器使用 `contain: inline-size` 让 Zotero 决定侧栏
宽度，避免长内容撑破面板；模板切换为自定义下拉，避免原生 `select` 弹层随
面板宽度调整闪烁。

`paper-theme.css` 保存纸面、文字、分隔线和功能色变量。仪表盘、配置编辑器、
元数据窗口与操作确认框加载该文件；插件创建的 Zotero 进度提示保留原有背景、
颜色、任务行为和关闭方式，仅调整字体。

`profile-manager.ts` 负责共享 AI 配置界面的创建、操作与清理，`ai-config.css`
控制列表、按钮和当前模型标记。配置观察器同步两处 AI 列表、概览信息和两类翻译的模型选项，
更新模型列表时保留文献翻译表单中尚未保存的输入。

## 本地化

`addon/locale/zh-CN/` 与 `addon/locale/en-US/` 覆盖偏好设置、配置编辑器和仪表盘
的基础文本。高级翻译面板与任务卡片仍包含源码内中文，后续需要迁移至 Fluent。
法语文档属于项目说明，插件界面当前没有法语资源。

## 测试状态

`test/startup.test.ts` 检查插件全局对象、条目菜单、自定义列和仪表盘工具栏按钮。
`test/features.test.ts` 检查标题译文元数据、综述来源格式与提示词持久化操作。
`test/translation.test.ts` 使用真实 Zotero 条目与指定 PDF，覆盖右键翻译、任务页
中间进度、完成状态及两类结果附件。`test/profile-manager.test.ts` 从仪表盘与原生
设置页面的实际按钮打开供应商编辑器，检查多 Key、模型和参数的填入、保存、取消与删除确认。
精读流程仍需补充完整自动化覆盖；启动测试已检查配置编辑器和元数据结果窗口的主要按钮样式。

发布候选版本需要完成以下验证：

- `npm run build`
- `npm run lint:check`
- `npm test`
- Zotero 10 中的安装、启停、偏好设置、菜单、窗口与附件导入验证
- `uv` 三种本地来源与 zotero-pdf2zh 服务端模式验证

## 发布流程

当前版本为 `0.1.8`。版本提交与远程发布分别执行。
项目脚本提供 `npm run release`，远程 GitHub Release 由推送版本标签触发 Actions 创建。
构建产物位于 `.scaffold/build/`。
