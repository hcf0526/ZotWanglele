# 阶段 1-2：项目骨架与 AI 服务层

## 阶段状态

项目骨架、AI 配置档、统一客户端和提示词持久化界面已经实现。Claude 与 Gemini 的
原生协议仍属于后续工作。

## 项目骨架

`package.json` 定义插件版本 `0.1.1`，插件 ID 为
`zotwanglele@wanglele.com`。构建链使用 zotero-plugin-scaffold、esbuild 和
TypeScript。

`src/hooks.ts` 负责以下生命周期行为：

- 等待 Zotero 初始化、解锁和 UI 就绪。
- 注册偏好设置面板。
- 为主窗口注册条目菜单与仪表盘工具栏按钮。
- 转发配置编辑器和仪表盘窗口事件。
- 在窗口卸载与插件关闭时移除 ztoolkit 注册项。

## AI 配置档

`src/modules/ai/profiles.ts` 将配置档序列化到 `ai.profiles`，并通过
`ai.activeProfileId` 记录当前配置。现有操作包含新增、编辑、删除、排序和当前
配置切换。首次运行会从旧版单配置字段迁移数据，并至少保留一个配置档。

内置服务商位于 `src/modules/ai/presets.ts`：

| 服务商      | 默认 Base URL                               | 默认模型                   | API 格式         |
| ----------- | ------------------------------------------- | -------------------------- | ---------------- |
| DeepSeek    | `https://api.deepseek.com`                  | `deepseek-chat`            | Chat Completions |
| OpenAI      | `https://api.openai.com`                    | `gpt-4o`                   | Responses        |
| Claude      | `https://api.anthropic.com`                 | `claude-sonnet-4-20250514` | Chat Completions |
| Gemini      | `https://generativelanguage.googleapis.com` | `gemini-2.5-pro`           | Chat Completions |
| Ollama      | `http://localhost:11434`                    | 用户填写                   | Chat Completions |
| SiliconFlow | `https://api.siliconflow.cn`                | 用户填写                   | Chat Completions |

预设用于填充配置字段。Claude Messages 与 Gemini 原生协议尚未实现，这两项预设
当前仍按 OpenAI 兼容格式调用，服务地址需由用户结合实际网关调整。

## AI 客户端

`src/modules/ai/ai-client.ts` 提供统一 `AiClient`：

- Chat Completions 请求使用 `/v1/chat/completions`。
- Responses 请求使用 `/v1/responses`。
- 两种格式均包含普通响应与 SSE 流式解析。
- HTTP `429`、`500`、`503` 可重试，默认最多重试两次。
- 配置编辑器通过短消息调用测试 API 可用性。
- 多模态消息辅助函数目前面向 Base64 PNG；精读流程尚未调用该函数。

## 提示词现状

`src/modules/ai/prompts.ts` 统一包含精读、摘要、方法分析、综述、标题翻译和标签等
模板，以及自定义模板操作与变量替换函数。内置模板的功能名称固定，系统提示词与用户
提示词可以通过仪表盘修改并恢复默认；自定义模板以 JSON 形式保存在 Zotero prefs，
仪表盘提示词页提供相应管理界面。

阅读、文献综述和标题翻译流程均通过统一模板 ID 读取当前提示词内容。

## 配置界面

偏好设置展示按服务商分组的配置档列表。独立编辑器可填写名称、服务商、API
格式、Base URL、API Key、模型、Temperature 和 Max Tokens，并提供 API 测试。
API Key 随配置档 JSON 保存于 Zotero prefs。
