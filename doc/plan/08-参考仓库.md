# 参考仓库

## 使用原则

以下项目用于功能研究与设计比较。ZotWanglele 当前实现以本仓库源码为依据，
规划条目代表未来方向。仓库内没有内置这些上游项目的源码副本。

## zotero-AI-Butler

- 仓库：<https://github.com/steven-jianhao-li/zotero-AI-Butler>
- 文档：<https://steven-jianhao-li.github.io/zotero-AI-Butler/>

参考方向包括 AI 笔记、PDF 多模态输入、多轮阅读、提示词、文献综述、思维导图
和侧栏布局。

当前对应关系：

| 方向             | ZotWanglele 状态                           |
| ---------------- | ------------------------------------------ |
| AI 笔记          | 已有索引文本单轮版本                       |
| 多模态 PDF       | 仅有 PDF Base64 辅助函数，阅读流程尚未使用 |
| 多轮与追问       | 待开发                                     |
| 提示词管理       | 内存函数已有，用户界面与持久化待开发       |
| 综述、导图、侧栏 | 待开发                                     |

## AI4Paper

- 仓库：<https://github.com/wdcpclover/ai4paper>
- 网站：<https://ai4paper.pro/>

参考方向包括标题翻译、自动标签、文献对比、综述深度和文献清理。ZotWanglele
当前仅在 `src/modules/ai/prompts.ts` 保留标题翻译、自动标签与综述提示词草案；
字段写入、标签管理、矩阵生成和清理模块均待开发。

## zotero-pdf2zh

- 仓库：<https://github.com/guaguastandup/zotero-pdf2zh>

ZotWanglele 当前服务端模式采用 zotero-pdf2zh 4.x 协议：

```text
GET  /health
POST /translate
GET  /translatedFile/<filename>
```

`POST /translate` 使用 JSON 和 PDF Base64，响应中的 `fileList` 提供结果文件名。
现有执行器已经按该协议实现健康检查、翻译提交和结果下载。

当前请求中的 `service` 为 `google`，对应 PDFMathTranslate 的 Google 机器翻译
后端。服务端也可提供其他翻译后端，其名称与凭据由服务端部署决定。

zotero-pdf2zh 的常见默认端口与本机部署设置可能不同。仓库测试记录采用
`http://127.0.0.1:9999`，详见 [测试资源说明](../../test/README.md)。

## 上游翻译引擎

- PDFMathTranslate：<https://github.com/Byaidu/PDFMathTranslate>
- PDFMathTranslate-next：<https://github.com/PDFMathTranslate/PDFMathTranslate-next>

本地模式通过 `uv run` 调用 `pdf2zh` 或 `pdf2zh_next`。通用
PDFMathTranslate REST 服务的 `/v1/translate/<task_id>` 轮询方案仅作为研究资料，
当前执行器未调用该组端点。
