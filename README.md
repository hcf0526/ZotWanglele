# ZotWanglele

ZotWanglele 是面向 Zotero 10 的 AI 阅读与 PDF 翻译插件。项目采用
TypeScript、zotero-plugin-scaffold 和 zotero-plugin-toolkit，以单个
`.xpi` 文件交付。

当前版本为 `0.1.7`，处于功能开发阶段。中文是主要界面语言，英文保留基础
本地化。

## 当前能力

### AI 配置与调用

- 管理多个 AI 配置档，支持新增、编辑、删除、排序和当前配置切换。
- 供应商由用户自由填写，编辑器支持添加多个 API Key，每个 Key 独立配置 Base URL 与 API 格式，并通过 `/v1/models` 获取模型或手动填写模型名称。
- 相同供应商的模型合并去重展示，调用时使用提供该模型的第一个 Key。翻译设置使用“供应商/模型名称”显示 Chat Completions 模型。
- 插件设置页面与仪表盘的“AI 配置”按供应商分组展示模型，上移、下移调整同组顺序。“设为当前”更新使用中的模型，两处界面同步显示；旧配置沿用原服务商名称。
- 统一支持 Chat Completions 和 Responses 两种 OpenAI 兼容格式。
- AI 客户端包含流式响应、重试和多模态消息辅助函数。
- 配置编辑器提供按 Key 获取模型列表的功能。

### PDF 精读

- Zotero 条目右键菜单提供“论文精读”和“快速摘要”。
- 从 Zotero 全文索引读取 PDF 文本，默认最多使用 60000 个字符。
- 多选条目采用串行处理，并在进度窗口显示执行状态。
- AI 结果保存为原条目的子笔记，Markdown 由内置轻量转换器生成 HTML。
- PDF Base64 读取函数已经存在；当前精读流程仍使用全文索引文本。
- Zotero 右侧条目面板提供“AI 笔记预览”，展示当前文献最新的论文精读和快速摘要子笔记。
- 预览区支持缺失笔记生成、自动刷新、手动刷新、打开原笔记、字号调整和高度拖动；PDF Reader 中会映射到附件的父文献。

### AI 笔记预览

在 Zotero 右侧条目面板打开“AI 笔记预览”区块，可以在当前文献旁边查看：

- “论文精读”“快速摘要”自定义下拉切换。
- 当前条目对应的最新子笔记。
- 没有笔记时直接生成对应内容。
- 刷新、打开原笔记、字号调整和拖动高度。

预览区使用纸感主题排版，内容宽度通过 `contain: inline-size` 与侧栏实际宽度
一致，长标题与长英文串在栏内断行，文字支持选中复制。选择 PDF 附件时，预览区
会自动使用它的父文献条目。右键菜单生成笔记完成后，预览区会随 Zotero 条目变化
自动更新。

### 划词翻译

在 PDF 中选中文字，点击原生批注浮层内的“翻译”。主窗口阅读侧栏的“划词翻译”
区块同步展示内容，关闭浮层后仍可查看和复制当前结果。独立 PDF 窗口使用浮层。

仪表盘的“划词翻译设置”提供功能开关、自动翻译、默认服务、源语言、目标语言和服务凭据。
默认使用当前 AI 配置，也可指定已有模型；DeepL 使用 API Key 与 Free／Pro 类型，
百度使用 AppID 和密钥。Google 为实验性免密钥服务，服务可用性由网络与提供方决定。

- 自动翻译开启后，选区停留 600 毫秒触发；默认由用户点击“翻译”。
- 单次最多 5000 个 Unicode 字符，Google 按最多 500 字符、百度按最多 1500 字符分段处理。
- AI 支持两种协议的流式输出，提示词可在仪表盘的“划词翻译”功能中编辑。
- 每个阅读器保留最多 50 条内存缓存；关闭阅读器后清空。结果用于查看与复制，文献库保持原状。
- 扫描 PDF 需要已有可选文本；上下文扩展、OCR 与词典功能属于后续候选。

### PDF 整文翻译

- 支持 `pdf2zh` 与 `pdf2zh_next`。
- 子进程模式包含 `uv-auto`、`uv-manual` 和 `bundle` 三种环境来源。
- 服务端模式使用 zotero-pdf2zh 的 JSON Base64 协议：
  `GET /health`、`POST /translate` 和
  `GET /translatedFile/<filename>`。
- 支持单语、双语输出，并将生成文件导入原 Zotero 条目。
- 仪表盘以任务记录展示内存中的翻译进度、日志与结果文件；批量翻译会为每篇文献保留独立记录。
- 翻译服务默认使用 PDFMathTranslate 的 `google` 后端，与 Gemini API 和 AI 配置档
  无关。

### 文献综述

- 对条目列表中选中的 2 至 30 篇文献生成结构化综述。
- 优先读取摘要；摘要为空时使用最多 8000 个字符的 PDF 索引文本。
- 综述包含带编号的题录、作者、年份与 DOI 上下文，便于核查来源。
- 结果保存为独立 Zotero 笔记，并加入当前选中的分类。

### 标题翻译

- 条目右键菜单与仪表盘均提供批量标题翻译入口。
- 译文写入条目的 Extra 字段，已有 Extra 内容会继续保留。
- Zotero 条目列表注册“标题译文”自定义列，支持排序、调整宽度和显示状态持久化。

### Crossref 文献信息更新

- 条目右键菜单提供“更新信息”，按 DOI 查询 Crossref REST API。
- 请求使用 `mailto=2971130350@qq.com` 和描述性 User-Agent，Crossref 公共查询无需 API Key。
- 对比窗口展示本地值与 Crossref 值，用户可以逐字段选择标题、作者、摘要、DOI 和日期。
- 多选条目按顺序查询并逐条确认，进度窗口汇总查询、更新、跳过和失败数量。
- 更新成功后在 Extra 中记录 Crossref 更新时间和联系邮箱，同时保留已有 Extra 内容。

### 用户界面

- 插件设置页面与仪表盘第二个页签均可管理 AI 配置。
- 独立配置编辑器用于填写服务商、Base URL、API Key、模型与生成参数。
- Zotero 工具栏按钮用于打开仪表盘。
- 仪表盘依次提供概览、AI 配置、任务记录、提示词管理、文献翻译设置和划词翻译设置六个页面。
- 任务记录使用可展开卡片展示摘要；PDF 翻译按文献分别记录，文献信息更新、标题翻译、AI 笔记和文献综述按一次操作聚合记录，并在详情中列出文献结果。
- 提示词管理分为三栏：左侧列出内置功能，中间列出该功能下的提示词模板，右侧编辑当前模板。
- 内置功能名称与说明固定；每个功能都有一套默认模板，也可新增自定义模板并设为当前使用。
- 自定义模板保存在 Zotero prefs，重新启动后仍可使用。

## 使用流程

### AI 精读

1. 在 Zotero 插件偏好设置中打开 ZotWanglele。
2. 添加供应商及 API Key，获取或填写可用模型。
3. 将需要使用的配置档设为当前配置。
4. 在文献条目右键菜单中选择“论文精读”或“快速摘要”。

PDF 需要具备 Zotero 全文索引。当前配置档需要填写 Base URL、API Key 和模型
名称。

### PDF 翻译

1. 通过 Zotero 工具栏打开仪表盘。
2. 在“文献翻译设置”中选择翻译引擎、输出类型、语言和翻译服务。
3. 使用“立即检测”确认运行环境。
4. 在文献条目右键菜单中选择“文献翻译”。
5. 在仪表盘的任务记录页面查看状态和详情。

服务端模式可填写类似 `http://127.0.0.1:9999` 的地址。子进程模式要求系统
中存在可用的 `uv`，或提供手动路径与 bundle 目录。

“翻译服务”默认值为 `google`，表示 PDFMathTranslate 的 Google 机器翻译后端。
插件会把服务名发送给 pdf2zh；服务所需密钥由 pdf2zh 运行环境提供。AI 配置档中
的 OpenAI、DeepSeek、Gemini 等 API Key 仅用于论文精读。

### 更新文献信息

1. 在 Zotero 条目列表中选中一篇或多篇带 DOI 的常规文献。
2. 打开条目右键菜单，选择“ZotWanglele → 更新信息”。
3. 在对比窗口逐项勾选需要接受的 Crossref 字段，选择“应用所选”。
4. 多篇文献会按顺序查询；每篇文献都可以单独跳过或选择字段。

Crossref 查询依赖网络连接。当前功能只读取条目的 DOI 字段，未填写 DOI 的条目会在进度窗口中标记为失败。

### 文献综述与标题翻译

1. 在条目列表中选择两篇或更多文献。
2. 从 ZotWanglele 子菜单选择“文献综述”。
3. 综述完成后，插件会选中新建的 Zotero 笔记。
4. 选择“翻译标题”可批量生成标题译文。
5. 在 Zotero 列选择器中确认“标题译文”列处于显示状态。

两项 AI 功能均读取当前 AI 配置档。标题译文保存在条目 Extra 字段的
`ZotWanglele-Translated-Title` 行中。

## 开发环境

- Windows PowerShell 7
- Node.js 与 npm
- Zotero 10
- TypeScript 5.9

```powershell
npm install
npm run build
npm run lint:check
npm test
```

`npm run build` 会生成生产构建并执行 `tsc --noEmit`。产物位于
`.scaffold/build/`。开发启动依赖本地 `.env` 中的 Zotero 路径与 profile
配置。

运行 pdf2zh 服务端功能测试时，需要提供固定样例路径，并保持 `9999` 服务可用：

```powershell
$env:ZOTWANGLELE_TEST_PDF = (Resolve-Path "test/attentionisallyouneed04.pdf").Path
npm test -- --no-watch
```

该测试会在临时 Zotero profile 中创建条目，通过右键菜单命令发起翻译，检查任务
页进度及单语、双语附件，并在结束时清理临时条目。

## 已知限制

- 当前精读流程依赖 Zotero 全文索引，并截取前 60000 个字符。
- 文献综述单次最多处理 30 篇，当前没有对比矩阵与引用格式选择。
- AI 配置档存于 Zotero prefs，API Key 会随配置档 JSON 保存。
- 统一任务记录仅保存在内存中，Zotero 重启后清空。
- 服务端翻译请求会等待服务完成，仪表盘目前没有服务端实时百分比。
- `uv-auto` 负责搜索已有 `uv`；自动下载 `uv` 尚未实现。
- Crossref 更新依赖条目已有 DOI；当前对比字段为标题、作者、摘要、DOI 和日期。
- Crossref 查询失败或取消对比窗口时，不会写入本地字段；批量流程按条目独立记录结果。
